# Introduction
This project explores what types of foods are considered the healthiest using pandas in a Jupyter Notebook.

### Background
Understanding nutritional information can help people make healthier food choices. The goal of this project was to explore a dataset of different foods and analyze the attributes that stood out.

### The question I wanted to answer through my data analysis questions was:
What attributes or patterns can be identified across different food categories?

# Tools I Used
Python: Used to load the dataset.
Pandas: Used to clean, manipulate, and summarize the data.
Matplotlib: Used to visualize data and make comparisons.
SciPy: Used to perform a chi-square statistical test to examine differences between plant-based and animal-based foods.
Jupyter Notebook: Used to write and execute the analysis.

# The Analysis
I analyzed a dataset containing 98 unique food entries from a list of the top 100 healthiest foods. 
I also categorized foods into plant-based and animal-based groups to investigate the differences in their representation.
Some of the main areas I explored included:
Comparing the number and percentage of plant-based versus animal-based foods.
Using statistical analysis to investigate whether the distribution of food types showed a significant difference.
Identifying patterns that could help explain why certain foods appear on a healthiest-foods list.

# What I Learned
Plant-based foods made up the majority of the dataset.
Data visualization makes nutritional comparisons easier to understand.
Statistical testing can help determine whether observed differences are meaningful.
Data analysis can turn raw nutritional information into useful insights.

# Conclusions
The analysis showed that plant-based foods were much more represented than animal-based foods in the dataset. This highlighted the important role that fruits, vegetables, and other plant-based foods play among nutrient-rich foods.
### Insights
Plant-based foods dominated: 91 out of 98 foods (92.86%) were plant-based, while only 7 (7.14%) were animal-based.
Nutrition matters: Foods provide different combinations of protein, fiber, vitamins, and antioxidants.

### Closing Thoughts
This project helped me strengthen my data analysis skills and better understand how to explore nutritional datasets. I learned how to use data analysis tools to summarize data, calculate percentages, and apply statistical methods. Most importantly, I learned that data analysis is not just about finding numbers but also about interpreting what those numbers mean and communicating meaningful insights.
